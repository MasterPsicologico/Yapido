# **App Name**: Finanzas Inteligentes

## Core Features:

- Chat Financiero Inteligente: Procesa lenguaje natural para interpretar y registrar datos financieros. Múltiples 'especialistas' de IA analizan la entrada para categorizar y dirigir las peticiones a las pestañas correspondientes (gastos, calendario, etc.)
- Registro de Gastos e Ingresos: Tabla organizada que muestra los gastos y las entradas registradas a través del chat. Permite la visualización y el filtrado de datos financieros por categoría, fecha y descripción.
- Integración de Calendario: Crea eventos y recordatorios en un calendario (ej. Google Calendar) directamente desde el chat, automatizando la programación de eventos financieros y recordatorios de pagos.
- Alertas Financieras Personalizadas: Genera alertas basadas en patrones de gasto y límites definidos por el usuario. Usa IA como un tool para ayudar a encontrar useful insights.
- Seguimiento de Presupuesto: Permite definir presupuestos mensuales para diferentes categorías de gasto y realizar un seguimiento del progreso en tiempo real.
- Visualización de Datos Financieros: Genera gráficos y resúmenes visuales de los datos financieros para identificar tendencias, patrones y áreas de mejora en la gestión del dinero.

## Style Guidelines:

- Primary color: Deep blue (#293462) to convey trust, professionalism, and intelligence.
- Background color: Very light gray (#F0F4F8), a desaturated variant of the primary color.
- Accent color: A vibrant teal (#00AFB9) to create contrast and draw attention to important elements like calls to action and key data points.
- Body and headline font: 'Inter', a sans-serif with a modern, neutral look.
- Use consistent and professional icons for categories, actions, and data visualizations.
- Clean and intuitive layout with clear visual hierarchy for easy navigation and data comprehension.
- Subtle animations for transitions and feedback to enhance user experience without being distracting.
