# **App Name**: Vitriniando

## Core Features:

- Registro y Gestión de Tiendas: Permitir a los comerciantes registrar y configurar sus perfiles de tienda, incluyendo información básica y detalles de contacto.
- Gestión de Productos por Tienda: Las tiendas pueden añadir, editar y eliminar sus productos, asignándolos a subcategorías dentro de su tienda con detalles, imágenes y precios.
- Catálogo de Tiendas y Productos: Interfaz de usuario para que los clientes puedan explorar fácilmente las tiendas registradas y los productos que ofrecen.
- Páginas de Detalle de Producto: Mostrar una página dedicada para cada producto con descripción completa, galería de imágenes y precio, accesible con un clic.
- Búsqueda y Filtros de Productos: Funcionalidad básica para que los clientes busquen productos o tiendas específicas y filtren resultados.
- Generador de Descripciones con IA: Herramienta de inteligencia artificial para ayudar a las tiendas a redactar descripciones de productos atractivas y optimizadas para la venta.

## Style Guidelines:

- Esquema de color principal: Un azul fiable y moderno (#3D88F2) para transmitir profesionalismo y claridad. Este color se ha elegido pensando en la dinámica del comercio y la conexión.
- Color de fondo: Un blanco roto muy claro con un toque azulado (#F0F4F7) para una estética limpia y legible en un esquema claro.
- Color de acento: Un cian vibrante (#07BBC9) para los elementos interactivos, llamados a la acción y detalles destacados, proporcionando un contraste enérgico.
- Fuente principal: 'Inter', un tipo sans-serif moderno y legible para todo el texto de la aplicación, desde titulares hasta párrafos de producto, lo que garantiza una interfaz limpia y objetiva.
- Uso de íconos lineales modernos y consistentes para la navegación y las acciones clave, asegurando una comunicación visual clara y un aspecto minimalista.
- Diseño adaptable y basado en tarjetas, optimizado para una fácil navegación y presentación clara de productos y tiendas en dispositivos móviles y de escritorio.
- Animaciones sutiles en los clics y transiciones de pantalla para mejorar la experiencia del usuario sin distraer, como resaltados al pasar el mouse o cargas progresivas.
